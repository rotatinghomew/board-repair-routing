# 电路板返修工位资料交换

`data/` 收录供演练使用的合成记录，不含真实企业或人员资料。资料使用 UTF-8 逗号分隔，首行为字段名，带逗号的单值用双引号括起。日期采用 ISO 表示，空字段表示来源未填或不适用，不代表数值零。`sources.json` 记录各表列名、身份键和可直接核对的引用。

## 业务资料

- `ontology.csv`：每行描述一种设备标签在给定可见条件下可以映射到的现场资质；ambig=1 表示不是自动确认。
- `boards.csv`：工件时点、可见材料及工艺；时间为班次内分钟。留出不参与定规则。
- `stations.csv`：人员、可并行资质与可到岗时间，同一人不能参与两单。既有 start/job 为已开始安排。
- `audits.csv`：抽查按起始分流与班次分层；revision 替代旧结论，known 记录被确认或者排除的范围。
- `scores.csv`：分数为各检测设备对自身标签的置信值，不同标签不保证和为一；没报的标签不代表阴性。
- `floor_review.csv`：现场可用的复审读数，不是事后拆检；新的 required 集合适用于该工件尚未开始的后续步骤。
- `loss.csv`：漏分或者需要联合资质的延误代价由返修制度定义。工时单独列，不与代价点数混用。

资料中的逗号表示技能集合。联合资质要求由不同持证人员同时在场；单人的多技能在一个时段可参与其中一种。Z 与 Y 是不同值班周期，开始时间均从当班零时刻计。一条拆检未列出的技能既非阳性也非阴性。

## 本地核对

需要 Python 3.11。分析环境可使用 `python3 -m pip install -r requirements.txt` 安装锁定的数值依赖。

从仓库根目录执行 `python3 check_sources.py`，返回各表行数；其他同格式资料可用 `python3 check_sources.py 路径` 检查。脚本只读资料并报告结构或引用错误，不给出业务结论。执行 `python3 -m unittest discover -s tests -v` 检查资料约定及拒绝重复身份的行为。
